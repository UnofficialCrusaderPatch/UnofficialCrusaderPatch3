# Framework 3.0.8

- Add the option to run multiple game instances and use separate logs per instance.
- Show the active setup digest on the main menu.
- Ask before running with security disabled from the command line.
- Fix ZIP directory alias listing and safe logging of AOB scan and extraction results.
- Faster startup: default AOB scans stop at the end of the game executable, and a cached AOB address is checked by comparing its bytes, and an entry that no longer matches is searched again on its own instead of clearing the whole cache.
- `core.matchesAOB(target, address)` tells whether an AOB matches at an address.
- `data.version.getGameLanguage()` reads the language name from the game folder's cr.tex when the game's language index is 0 (English or a name the game does not know): "Русский" is "russian", other names are returned in lowercase. It returns "spanish" in lowercase.
- The userdata interface accepts `_` in paths and adds `rename(from, to)`, which replaces an existing file in one step.
