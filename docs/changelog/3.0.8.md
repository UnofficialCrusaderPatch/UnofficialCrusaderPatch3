# Framework 3.0.8

- Add the option to run multiple game instances and use separate logs per instance.
- Show the active setup digest on the main menu.
- Ask before running with security disabled from the command line.
- Fix ZIP directory alias listing and safe logging of AOB scan and extraction results.
- Opening a directory entry or a file that cannot be extracted from an extension zip fails with a message instead of giving an empty file.
- Faster startup: AOB scans without a range search the game executable's image instead of memory up to 0x7FFFFFFF (pass an explicit range to search outside it), `core.AOBScan` caches the address it finds for any range and reuses a cached address that starts in the range, a cached AOB address is checked by comparing its bytes, and an entry that no longer matches is searched again on its own instead of clearing the whole cache.
- `core.matchesAOB(target, address)` tells whether an AOB matches at an address.
- `core.AOBScanUnique(target)` returns the address of an AOB that occurs exactly once in the game executable's code, or nil and "not found", "found more than once" or "not searched completely". A unique address is cached and reused while the bytes there still match. `--ucp-allow-multiple-instances` uses it.
- RPS 1.6.0: a scan with a range returns the first match that starts from `min` to `max` (`start` to `stop` for `core.AOBScan` and `utils.AOBExtract`), both included, and no longer one that starts after `max`. It does not read past the end of a memory region.
- `data.version.getGameLanguage()` reads the language name from the game folder's cr.tex when the game's language index is 0 (English or a name the game does not know): "Русский" is "russian", other names are returned in lowercase. It returns "spanish" in lowercase.
- The userdata interface accepts `_` in paths and adds `rename(from, to)`, which replaces an existing file in one step.
- `io.lastWriteTime(path)` returns a comparable filesystem timestamp for a regular file. It uses UCP's relative paths and aliases and returns nil and a reason for missing files, ZIP entries or paths outside the framework's file access rules.
- `io.gameRelativePath(path)` converts an absolute path inside the game directory to a path for UCP file APIs. It returns nil and a reason if the path cannot be expressed inside the game directory.
